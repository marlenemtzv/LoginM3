## Descripción
Pantalla de login con validación de campos. Se adapta al modo claro y oscuro, y cambia de colores según el fondo de pantalla del teléfono gracias a Material You.

## Características
- Tema Material 3 (`Theme.Material3.DayNight.NoActionBar`)
- Material You con `DynamicColors`
- Campos con `TextInputLayout` y ícono para mostrar u ocultar la contraseña
- Validación de correo (formato válido) y contraseña (mínimo 6 caracteres)
- Mensajes de error en cada campo y `Snackbar` cuando los datos son correctos
- Casilla "Recordarme" y botones "¿Olvidaste tu contraseña?" y "Crear cuenta" (en este prototipo solo muestran un aviso)
- Diseño con `ScrollView` y `LinearLayout` para adaptarse a distintos
